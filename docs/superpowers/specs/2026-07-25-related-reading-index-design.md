# 阅读余韵索引：相关文章模块设计

**日期：** 2026-07-25  
**状态：** 待审阅  
**范围：** 博客详情页的“相关文章”模块视觉与交互重设计

## 1. 背景与目标

现有“相关文章”模块虽然已经移除了嵌套卡片，但仍表现为通用的组件列表：标题、标签和链接的层级偏向产品信息流，与文章页现有的衬线标题、纸张感、留白和连续阅读节奏不一致。

本设计将模块重构为“阅读余韵索引”：它是正文结束后的阅读延伸，而不是推荐卡片或信息流广告。

### 目标

- 保留最多 3 篇相关文章的站内内链和现有排序逻辑。
- 让模块在文章正文后自然收束并引导继续阅读。
- 复用当前主题令牌和字体，不引入新颜色、字体、阴影或卡片体系。
- 支持键盘访问、移动端触达和 reduced-motion。

### 非目标

- 不改变相关文章的检索、排序、去重与数量上限逻辑。
- 不改变文章详情页的正文、版权、分享、评论或上下篇模块。
- 不新增图片、封面、评分、点赞或异步加载状态。

## 2. 信息结构

模块置于 `ArticleCard` 之后、版权信息之前：

```text
正文
├─ 阅读余韵索引（相关文章）
├─ 来源 / 版权信息
├─ 分享与互动
└─ 评论
```

模块仅在 `relatedPosts.length > 0` 时显示。每项使用现有数据：

- `number`：项目序号与链接生成。
- `title`：主标题。
- `summary`：可选摘要。
- `sharedLabels`：与当前文章重合的标签。

## 3. 桌面布局

```text
──────────────────── ◇ ────────────────────
继续阅读                                      3 篇同题文章

01   文章标题                                      →
     摘要最多两行，说明为什么值得继续阅读。
     #标签一 · #标签二

02   第二篇文章                                    →
     摘要……
     #标签一
```

### 模块头部

- 顶部使用一条低对比度细分隔线，中间为 CSS 绘制的菱形，不使用 emoji 或新图标资产。
- 左侧标题为“继续阅读”，采用 `--font-serif`、`--font-size-base`、500 字重。
- 右侧辅助信息为“{count} 篇同题文章”，采用 `--font-size-xs` 和 `--text-muted`。
- 不使用外层背景、边框圆角或阴影。

### 列表项

- 每项为完整可点击链接，采用 CSS grid：`序号 | 内容 | 箭头`。
- 序号为两位数（`01` 至 `03`），使用弱对比度 sans 字体作为阅读索引，不作为唯一信息载体。
- 标题使用正文主文字色，单行截断。
- 有摘要时显示两行截断；无摘要时不渲染该区域，不保留空白。
- 标签以低强调文本呈现，如 `#daily · #随笔`，不使用彩色 Tag pill。
- 项目间使用细分隔线；最后一项不使用额外底线。

## 4. 交互与状态

### 鼠标与键盘

- 整项链接是唯一交互目标；不拆分标签或箭头为独立链接。
- Hover 时标题和箭头变为 `--primary-color`，箭头向右平移 3px。
- 不使用卡片抬升、阴影、背景闪烁或整块位移。
- `:focus-visible` 使用现有主色 2px outline 和 2px offset，焦点覆盖整项。
- 焦点顺序与视觉顺序一致。

### 动效

- 仅箭头使用 160–200ms 的 transform/color transition。
- `prefers-reduced-motion: reduce` 下移除 transform transition。

## 5. 响应式规则

| 视口 | 规则 |
|---|---|
| > 640px | 序号、内容、箭头三列；辅助计数在模块标题右侧。 |
| ≤ 640px | 仍保留序号和箭头；内容列弹性收缩；辅助计数移到标题下方或自动换行。 |
| ≤ 420px | 摘要最多两行，标签可换行；链接最小交互高度为 44px。 |

禁止横向滚动。标题、摘要和标签必须能在窄屏优雅截断或换行。

## 6. 主题与可访问性

- 所有颜色使用现有 CSS 变量：`--text-primary`、`--text-secondary`、`--text-muted`、`--primary-color`、`--accent-color`。
- 常规文本与背景保持至少 4.5:1 对比度；弱化信息不承担唯一语义。
- 摘要是辅助内容，屏幕阅读器仍按标题、摘要、标签的自然顺序读取。
- 箭头设置 `aria-hidden="true"`；链接可补充 `aria-label="继续阅读：{title}"`。
- 不依赖 hover 传达关键内容或唯一操作。

## 7. 组件边界与实现约束

建议保留现有 `RelatedPostsSection`、`RelatedPostLink`、`RelatedPostTitle`、`RelatedPostLabels` 的命名，但将其样式与 JSX 结构调整为索引式布局。

新增的表现层元素：

- `RelatedPostsHeader`：标题、计数和装饰分隔线。
- `RelatedPostIndex`：序号。
- `RelatedPostSummary`：仅在存在 `summary` 时渲染。
- `RelatedPostArrow`：非交互装饰箭头。

不需要修改 `selectRelatedPosts`、服务端请求或共享 DTO。

## 8. 验收标准

1. 相关文章存在时显示“继续阅读”和准确数量；不存在时不渲染模块。
2. 每一项整行可点击，键盘焦点清晰可见。
3. 有摘要显示至多两行；无摘要不留空白。
4. 标签以文本形式显示，不显示彩色胶囊标签。
5. 桌面端不出现卡片背景、圆角容器、阴影或 hover 抬升。
6. 375px 宽度下无横向滚动，单项触达高度不低于 44px。
7. reduced-motion 下无箭头位移。
8. 现有相关文章排序、上限、SEO 内链和详情页结构化数据保持不变。
