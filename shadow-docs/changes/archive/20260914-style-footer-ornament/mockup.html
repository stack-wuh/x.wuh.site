移动端（< 640px 语义断点）

  • · 触屏无 hover：末行显示「图标 + 文字」，不依赖交互
  • · meta 文案自然折行，链接按内容换行排列
  • · 断点使用语义常量 mobile 640 / small 520，替换现有硬编码 768px
  • · logo 嵌入分割线中心（84×42），移动端缩至 68×34，不再独立占位

设计说明

  • 层级（上→下）：ornament 分割线（logo 居中锚点）→ serif slogan（17px）→ 导航行（博客 / 关于 / RSS）→ 备案链接行 → 版权注脚（协议 + 驱动）→ 站点数据行（三项图标，最弱层级）
  • 复用组件：Divider variant="ornament"（两侧线 transparent → primary 45%，logo 作为 children 居中锚点（替代默认字符 ◇），W 线条取 currentColor、色块取 primary）
  • 交互：链接 hover 180ms ease-out 文字提亮 + 1px 中段渐隐下划线（Header 导航同语言）；focus-visible 有 primary 描边 ring
  • 末行图标（三项）：日历 = 运行天数 · 羽毛笔 = 全站字数 · 眼睛 = 访问量（总访问量与今日合并，tooltip/标签内并列展示，避免眼睛与折线两枚图标难以区分）；桌面 hover/focus 弹 tooltip（向上，避免页底裁切），触屏常显文字；图标带 sr-only 文案与 tabindex，键盘可聚焦
  • 新增内容：备案号链接化（工信部 / 公安备案平台）、站内导航行、CC BY-NC-SA 4.0 协议、站龄（footerConf.siteBorn = 2021-03-08 备案审核日起算）与全站字数，置末行「站点数据行」、全站字数（扩展 GET /api/visit-stats/stats 返回 totalWords）
    留言板：/about 页内区块，导航不单列，并入「关于」
