光标比稿 v4
活体物件，不是图案 · pointer:fine 门控 · reduced-motion 落静帧

上一轮否到底的不只是蝴蝶，是「用光标画一个东西」这件事本身——画什么都要越少越残。本轮换骨架：光标是一枚正在被你使用的物件。四个互斥骨架，按人设取四源：本站主体的书（阅读 · 你点名的方向）、夜读的灯、庄子的鱼（文艺 × 游标/摸鱼）、毕昇与 vim 的字模（程序员）。每套都只有 2–4 个元件，六态不换形状、只换物件的使用状态。

甲 · 一豆灯

热点 = 灯芯豆。火苗悬在触点正上方，你走到哪，光跟到哪：提灯夜读。移动时身后落三点火星（拖尾即光痕），是唯一一个「走过留痕」的骨架。

乙 · 一尾鱼

热点 = 吻尖。三个元件：一笔身、一尾鳍、一粒朱眼。它认得你往哪儿去——头随移动方向转（EMA 平滑 + 限速倾角），停下来才回到斜倚定姿，游得越快摆尾越急。文艺是「子非鱼」，程序员是「游标」与摸鱼；「cursor」一词本义即游标，这是唯一一套把词源演出来的。

移进此区：鱼头会转向你的去向。试试快速划动、原地停住

丙 · 活字（字模 ▮）

热点 = 字模左缘中点，与 vim / 终端块光标同一取位。两个元件：一方空字模 + 一横朱砂墨脚。没沾墨时是框，hover 即着墨，进输入框收成竖线并按终端节奏闪烁（1.06s steps），加载时字模里三道墨位轮转，按住即钤出一枚阳文朱印。文艺是毕昇，程序员是光标本身——两套身份压在同一个几何形上，不靠画出来的东西撑特色，因此不存在画丑的风险。

丁 · 一页书（定稿候选 · R2 曲线轮）

热点 = 画布锚 (4,4)、书形整体右下平移 (6,6)（R4 明显错开），指针对位处空出 ~6px，书页摊向右下；脊头钉 (12,3.6) 为装订点。元件：左页、右页、一页会自己动的翻页（带 1.5px 弧边纸口）、底页三行弧字、一痕朱脊 + 一枚脊头钉、一道只在输入态拉开的朱基线。页面是真纸色：左页铺 `--background-100`（笺纸白）、右页压一层淡茶（`--faint` .22，纸背比纸面暗）、翻页那张最亮并带 1.5px 弧边——R3 前页面是空的，白纸不挡底，翻页掠过去时页面里的内容从纸下透上来，假。形幅 15.4×11.6，R2 起全部直边改贝塞尔：页面上缘向书口扬起、书口微外凸，三行淡字沿纸面弧度走，翻页带弧边厚度——粗糙感来自"直线贴在弧面上"，一根都不留。hover 掀页欲读、进输入框压成一行、加载哗哗翻书、拖拽合卷、按住压紧、点击落一记。它和写意蝶是同一个轮廓——两页即两翅，差别在于书是「被使用的物件」，不是被画出来的虫。

态物件在做什么
default摊卷静置（15.4×11.6，叶形扬边 + 圆头描边），5.4s 一轮风掀两记（先 .55 小掀、再 −.42 大掀）——大部分时间是静的
idle · 自读书静止 ≥5s：风掀升级为整页翻——从右页掀起、越过书脊、落在左页、化去（idleTurn 3.4s 一页）。指针一动立即收回风掀，进任何交互态则被该态接管（规则序在 hover/输入/拖拽之前）。书停在原地时，它在读。
pointer掀页欲读：翻页停在半开（scaleX 1↔.08，1.05s）、弧边纸口 1.5px 随动，底页显形到 .18 并浮出三行弧线淡字
text两页压成一行（scaleY .36）+ 一道朱基线拉开（scaleX 0→1，240ms）——书即一行文本
wait不断翻书：一页绕书脊 1↔−1 来回，.52s alternate，哗哗地读。行林此时不上——翻得太快只剩灰噪，删（R1 除饰品）
grab / grabbing合卷成册（两页收到 .5/.4）；按住持续压紧（左页 .3 合、右页 .44×.72 压）
click左页轻合一记（260ms，不循环）作按压反馈
热点锚 (4,4) + 右下偏移 (6,6)：指针与书页之间 ~6px/14px 视觉间隙，对位不被压；书脊装订点不再当锚（R4）
全站一致纪律（四套通用）：单一 rAF 全局跟随层，translate3d 合成器位移，全部动画 transform/opacity、走 --motion-* 令牌；热点即触点（灯芯豆 / 鱼吻 / 字模左缘），开热点十字自检。降级：粗指针或 prefers-reduced-motion → 交还 CSS cursor，用每套下方那组静帧 SVG（生成期按 4 主题调色板注入实色 data URI，墨走 --text-color、朱走 --primary-color，零裸 hex 入仓）。六态全覆盖，静态帧与动效稿同一支笔。
