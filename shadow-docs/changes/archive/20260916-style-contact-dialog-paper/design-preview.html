提案相对现状的具体变更（视觉层）

  1. 表面：圆角 16px 硬编码 → --border-radius-base(8px)；rgba 边框 → 发丝线 color-mix(normal-300 45%)；重阴影 0 12px 50px → --elevation-soft（与主题选择弹层同语言）
  2. 宽度：760px → min(640px, 100vw-32px)，降低右栏空旷感；两栏 gap 48 → 28（md cap）
  3. Header：通用发丝分割线 → 渐隐墨线（两端透明、中段 color-mix(primary 45%)，与导航运笔下划线同源）；标题前加渠道钤印（22×22 印框、衬线首字、装饰性 aria-hidden）
  4. 大按钮：圆角 24px → 12px（md）；二维码加白边裱框（8px paper mat）；hover 上浮保留，过渡统一 180ms ease-out
  5. 信息区：handle 改等宽字体；层级间距收紧（6px 节奏）；logo 占位为示意（实际用站内 IconLogo）
  6. Hints：墨点用 color-mix(primary 60%)（现状为 40% 灰点）
  7. 动效：内容三段 write-fade 错峰入场（大按钮 0ms → 信息 80ms → hints 160ms，400ms ease-out-soft）；prefers-reduced-motion 停用
  8. 响应式：560px 裸断点 → BREAKPOINTS.mobile(640)，与弹窗底部滑入同轴；移动端单列居中、二维码 184、hints 纵排
  9. 3D 手势（本次追加）：二维码大按钮指针跟踪倾斜——perspective(700px) + rotateX/rotateY ±12° 跟随指针（140ms ease-out 惯性跟手），transform-style: preserve-3d 下白边裱框 translateZ(28px) 浮于纸面、纸面泛暖金（--accent-color）径向高光随指针移动并越过裱框罩全纸面（纯白高光在 wine light 奶白纸面上不可见，已换 accent 光泽）；触屏（hover: none）与 prefers-reduced-motion 下完全停用，不影响点击语义（二维码仍进预览、链接仍跳转）；实现走 CSS 变量直写 DOM，避免 React 重渲。倾角 / 浮起 / 透视三参数以顶栏滑杆定稿值为准（本稿即视觉验收基准）
