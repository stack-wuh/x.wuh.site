微动效可选层 ·「墨晕拖尾」

加分项，不绑定比稿方向：系统光标隐藏，笔尖墨点+呼吸光晕以 150ms ease-out-soft 滞后追随；悬停可点元素时墨点化作闪烁的朱色方块光标 ▮（1.06s steps 终端式闪烁，全页最程序员的一刻），离元素即收回。仅在 pointer:fine 且非 reduced-motion 时启用，否则整体瞬切回所选构的静态光标。

动效 Icon ·「会呼吸的墨」——JS 绘制跟随层（cursor:none 接管舞台区）

CSS cursor 不能动画，动 = 隐藏系统光标、墨层实时绘出。行为全集：待机 = 钩尖朱砂呼吸明灭（2.4s）；hover 链接/按钮 = 朱点钤印张环；按下 = 一圈墨晕扩散（300ms）；进输入框 = 光标化作 ▮ 终端方块闪烁（1.06s steps 真实闪烁节奏）；拖拽按住 = 压扁回弹。全部 transform/opacity、走 --motion-* 令牌缓动；reduced-motion / 触控 / JS 不可用 → 瞬切上方所选构的静态 SVG（静态稿即回退资产，不白画）。笔身可在 F 竖钩 / G 刻刀 间切换——动效与形体正交。

写意蝶 · 两笔一点

以笔写蝶，不以翅写蝶：左叶一笔、右叶一笔、中粒朱砂——就是这只蝶。无翅脉、无斑点、无触须、无节腹、无生命谱系叙事。六态皆同一两笔的开合：待机微呼吸、hover 快扇、按下波动一记、输入合翅成一线、拖拽急扇、加载合翅入定。朱点即热点，蝶身悬于目标正上方。
