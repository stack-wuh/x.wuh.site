## 5. 视觉规范（Design Tokens）
> 目标：把“视觉选择”沉淀为 tokens，保证卡片/按钮/标签/信息块等处可复用与一致。

### 5.1 颜色（主题：人民币 100 元）
| 类型 | 色值 |
|---|---|
| 页面深背景 | `#7B5A5A`（可叠加噪点/渐变） |
| 卡片背景 | `#FFF3F0` |
| 主色（Primary Red） | `#C94A44` |
| 主色 Hover/Active | `#A13531` |
| 强调色（Accent Gold） | `#E3B567` |
| 辅助暖灰 | `#8D6E63` |
| 正文文字 | `#1F1F1F` |
| 次级文字 | `#8A7A7A` |
| 分隔/边框 | `rgba(0,0,0,0.06)` |
| 链接/辅助色（可选） | `#41B5A8` / `#F2A154` |

补充：若需“素雅主题”，可用暖米白 + 棕灰 + 少量朱红，通过 CSS variables 切换（具体色值 TBD）。

### 5.2 字体与排版（Typography）
- Hero 主标题：56px
- Hero 副标题：20–24px
- 模块标题：28–32px
- 正文：18px
- metadata：14–16px
- 行高：1.5–1.7
- 正文最大行宽：约 70–80 字符

### 5.3 间距系统（Spacing）
- 8pt 间距系统：8 / 16 / 24 / 32 / 40 / 64 / 80

### 5.4 圆角与阴影（Radius & Shadow）
- 卡片/容器圆角：16–20px
- 标签/胶囊：999px
- 阴影（默认）：`0 20px 40px rgba(0,0,0,0.08)`
- 阴影（hover）：`0 30px 50px rgba(0,0,0,0.12)`

## 6. 页面结构与布局（Page Layout）
### 6.1 顶部导航与 Hero（首页）
- 导航内容：Logo + 菜单项（博客 / 知识库 / 标签 / 关于 / RSS）
- Hero 结构：深色渐变背景 + 浮层卡片
  - 左侧文字、右侧插画/装饰
  - 底部加入“向下滚动”提示或 CTA

### 6.2 精选博客与列表
- 主容器宽度：1100–1200px，居中
- 精选模块：标题 + “查看全部”按钮 + 卡片栅格
  - 桌面：3 列
  - `<=1024px`：2 列
  - `<=768px`：1 列
- 普通列表：复用同一卡片样式与信息层级

### 6.3 文章详情页（阅读体验）
- 正文宽度：780–820px，居中
- 元信息展示：icon + 文本列表（作者、时间、标签、许可证、原文）
- TOC/侧边导航：
  - 桌面端：提供 TOC 或侧边导航
  - 移动端：折叠或置底

## 7. 组件规范（Component Specs）
### 7.1 卡片（Card）
- 背景：`#FFF3F0`
- 圆角：20px
- 结构：标题区域 → 摘要 → metadata + 标签 + CTA
- Hover：上浮 4px、阴影加深，箭头或按钮渐显

### 7.2 标签（Tag）
- 胶囊样式：字体 12–13px，padding 4px 12px
- 可用淡渐变背景：例如 `#FDE4E4 → #FFF3F0`
- 文本颜色：主色或辅助色（随主题 tokens 统一）

### 7.3 按钮（Button）
- 主按钮：渐变（`#C94A44 → #A13531`），高度 48px，hover 添加“光泽”
- 次级按钮：outline + 毛玻璃背景（半透明 + blur），hover 时填充浅色
- icon + 文本/tooltip：保持可访问性（aria/可聚焦/对比度）

### 7.4 信息列表（Info List）
- 布局：图标 + 标签 + 内容（三列栅格）
- 移动端：改为纵向
- 图标来源：Iconfont（沿用现有）

### 7.5 评论与空状态（Comment / Empty State）
- 空状态卡片：插画/emoji + 标题 + 描述 + CTA（如“订阅更新”）
- 边框：虚线或渐变边框，区别于常规卡片

### 7.6 底部导航（上一篇/下一篇）
- 卡片：渐变背景、箭头动效；hover 箭头滑动
- 移动端：放在正文下方，宽度 100%，按钮高度 ≥56px

## 8. 动效与交互（Motion & Interaction）
- 卡片/按钮 hover：
  - `transform: translateY(-4px)`
  - `transition: 180ms ease`
- 模块进入动画：淡入 + 上移（stagger 120ms）
- Hero 滚动提示：循环箭头动画
- 加载状态：骨架屏或 shimmer 动效（可选）
- 错误提示：统一 snackbar（圆角 + 渐变背景 + 自动消失，可选）
- Focus：主色描边 + `outline-offset`，键盘导航可见

## 9. 响应式与可访问性（Responsive & A11y）
### 9.1 主题与可访问性
- 主题能力：采用 CSS variables 构建深浅主题，预留浅色方案
- 对比度：文本/背景对比度 ≥ 4.5:1
- 交互可达：所有交互元素具备 `:focus-visible` + 合理 `aria-*`

### 9.2 响应式断点
- `>1280px`：内容居中，3 列卡片，显示侧边 TOC/导航
- `1024–1279px`：卡片 2 列；TOC 固定右侧或折叠
- `768–1023px`：Hero 图文上下排列；按钮/图标两列；信息列表垂直
- `<768px`：单列；容器 padding 16px；导航折叠为 hamburger；卡片全宽；底部导航与社交按钮堆叠

## 10. 验收标准（Acceptance Criteria）
- 视觉一致性：卡片/标签/按钮/信息块在首页列表、精选模块、文章详情页视觉一致（圆角/阴影/间距/字体层级一致）。
- 阅读体验：文章正文行宽、行高与对比度符合规范，metadata 信息清晰不喧宾夺主。
- 交互反馈：hover/进入动效存在且不喧宾夺主；移动端无明显掉帧（主观验证）。
- 响应式：在 `>1280px / 1024 / 768 / <768` 四档验证布局符合上述策略。
- 可访问性：可通过键盘遍历主要交互区域；focus 样式清晰可见；对比度达标（抽样验证）。
- 资源约束：Iconfont 与插画沿用，不引入新依赖（除非你确认允许）。
