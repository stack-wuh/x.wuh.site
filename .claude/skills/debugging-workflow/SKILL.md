# 系统化调试

## 规则（必须遵守）

1. 遇到任何 Bug 必须先调用 systematic-debugging，禁止猜测式修复
2. 必须先复现再修，禁止"试试这个行不行"
3. 修复后必须回归检查

## 执行步骤

1. 调用 Skill("superpowers:systematic-debugging")
2. 先复现：写能稳定复现的测试或用例
3. 再分析：定位根因，不要猜测
4. 最后修：最小改动修复，验证复现用例通过
5. 回归检查：确保修复没有引入新问题

## 完成标准

- Bug 根因已定位（不是"好像好了"）
- 复现用例通过
- 相关测试全部绿色

## 反模式

- 猜测式修复 — 不理解根因的修复大概率引入新 bug
- 修完不复现 — 不知道是否真的修好了
- sleep / try-catch 吞异常 — 掩盖根因而非修复
